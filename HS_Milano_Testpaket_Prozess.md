## TESTPAKET-PROZESS (Detailliert)

### PHASE 1: KONTAKT & DEAL-ERSTELLUNG
├─ Voraussetzung: Testformular ausgefüllt
├─ Kontakt in HubSpot angelegt (mit Namen, E-Mail, Telefon)
└─ Aktion durch: HubSpot (automatisch) oder Vertriebsteam

**Was wird erstellt:**
├─ Deal mit Namen (aus Anmeldedaten des Kontaktes)
├─ Unternehmen mit Namen (aus Anmeldedaten)
└─ Dealstage: "Testpaket angefragt"

**Wichtig:** Alle Infos müssen den Anmeldedaten entnommen werden

---

### PHASE 2: QUALIFIKATION - KONTAKTAUFNAHME
├─ Verantwortlicher Kontakt: Zuständiger Verkäufer
├─ Aufgabe: Interessenten anrufen und qualifizieren
│
├─ ANRUFVERSUCHE - Strategie bei Nichterreichbarkeit:
│  ├─ Versuch 1-3: Anrufe durchführen
│  │
│  ├─ Nach Versuch 3 (falls nicht erreichbar):
│  │  ├─ Wenn Mobilnummer vorhanden:
│  │  │  └─ WhatsApp mit Rückruf-Bitte versenden
│  │  └─ Sonst:
│  │     └─ E-Mail versenden
│  │
│  └─ Nach Versuch 6 (keine Erreichbarkeit über alle Kanäle):
│     ├─ Dealstage: "Verloren"
│     └─ Deal wird abgeschrieben
│
└─ BEI ERFOLGREICHER KONTAKTAUFNAHME:
   ├─ Leitfaden "Qualianruf" durchführen
   ├─ Kurzes Telefonat führen
   └─ Zum Ende des Gesprächs:
      └─ Termin für ERSTES BERATUNGSGESPRÄCH vereinbaren
         ├─ Format: Google Meet
         ├─ Zeitnah zum Testpaket-Versand
         └─ In HubSpot als Termin eintragen

---

### PHASE 3: AFTER QUALIANRUF - NEUKUNDENMAIL
├─ Zeitpunkt: Direkt nach dem Qualianruf-Gespräch
├─ Automatische Aktion: E-Mail "Neukundenmail" versenden
├─ Empfänger: Der Interessent
└─ Inhalt: (Siehe Vorlage "Neukundenmail")

---

### PHASE 4: TESTPAKET-ERFASSUNG (TOM's Aufgaben)
├─ Verantwortlicher: Tom
│
├─ WICHTIGE REGEL - Ahmet Yitik Affiliate-Provision:
│  ├─ Wenn Kontakt "Ahmet Yitik" zugeordnet ist:
│  │  └─ Affiliate darf ERST NACH Erfassung des kostenlosen Testpakets Ahmet zugeordnet werden
│  │     (Grund: Provisionsvereinbarung)
│  └─ Ablauf:
│     ├─ 1. Kunde in Shopware anlegen (OHNE Ahmet als Affiliate)
│     ├─ 2. Kostenloses Testpaket erfassen
│     ├─ 3. DANN Ahmet als Affiliate zuordnen
│
├─ Aufgaben Tom:
│  ├─ Kunde in Shopware anlegen
│  ├─ Kostenloses Testpaket erfassen
│  │  ├─ Paketgröße wählen (Klein/Mittel/Groß?)
│  │  └─ Kundendaten korrekt einpflegen
│  │
│  └─ Nach erfolgreicher Erfassung:
│     └─ Dealstage: "Testpaket erfasst"
│
└─ Ergebnis: Testpaket ist bereit zum Versand

---

### PHASE 5: WILLKOMMENSCODE & ERSTES BERATUNGSGESPRÄCH
├─ Nach Testpaket-Erfassung:
│  ├─ E-Mail mit Willkommenscode 20% versenden
│  └─ Empfänger: Der Kunde
│
└─ Im Erstes Beratungsgespräch (Google Meet):
   ├─ Leitfaden "Erstberatung" durchführen
   ├─ Besprechen: Dauer der Testphase
   ├─ Vereinbaren: Termin für FEEDBACK-GESPRÄCH
   │  └─ In HubSpot als nächsten Termin eintragen
   └─ Ziele festlegen für die Testphase

---

### PHASE 6: TESTPHASE (LAUFEND)
├─ Dauer: Individuell besprochen im Erstgespräch
├─ Kundenverantwortung: Testpaket aktiv nutzen
│  ├─ Funktionen testen
│  ├─ Mit realem Geschäft arbeiten
│  └─ Feedback sammeln
│
└─ Supportteam-Verantwortung:
   ├─ Verfügbar für Fragen
   ├─ Probleme schnell lösen
   ├─ Zusätzliche Schulung bei Bedarf
   └─ Fortschritt überwachen

---

### PHASE 7: FEEDBACK-GESPRÄCH
├─ Zeitpunkt: Im Erstgespräch vereinbart
├─ Format: Telefonat oder Google Meet
├─ Teilnehmer: Kunde und Account-Manager
│
├─ Inhalte besprechen:
│  ├─ Wie war die Testphase?
│  ├─ Was hat gut funktioniert?
│  ├─ Welche Probleme gab es?
│  ├─ Erfüllt das System die Anforderungen?
│  ├─ Offene Fragen klären
│  └─ Nächste Schritte besprechen
│
└─ Ergebnis: Grundlage für Kaufentscheidung

---

### PHASE 8: KAUFENTSCHEIDUNG
├─ Kunde entscheidet sich:
│  ├─ JA - Kunde will das System kaufen
│  │  └─ → Weiter zu PHASE 9 (Umstieg auf Bezahlversion)
│  │
│  └─ NEIN - Kunde interessiert sich nicht weiter
│     ├─ Dealstage: "Verloren" (mit Grund dokumentieren)
│     ├─ Feedback-Gespräch führen: Warum nicht?
│     ├─ Verbesserungspotenziale erfassen
│     └─ Türe offen halten für zukünftige Zusammenarbeit

---

### PHASE 9: UMSTIEG AUF BEZAHLVERSION
├─ Nur bei positiver Kaufentscheidung
│
├─ Lizenz-Details klären:
│  ├─ Anzahl der Benutzer
│  ├─ Laufzeit (1, 2 oder 3 Jahre?)
│  ├─ Zusatzfunktionen gewünscht?
│  └─ Preis kalkulieren
│
├─ Administratives:
│  ├─ Lizenzvertrag erstellen / anpassen
│  ├─ Rechnung ausstellen
│  ├─ Zahlungsbedingungen festlegen
│  └─ Zahlungsbestätigung abwarten
│
├─ Technische Vorbereitung:
│  ├─ Produktionsumgebung bereitstellen
│  ├─ Alle Kundenberechtigungen setzen
│  ├─ Kundendaten aus Test in Produktion migrieren
│  └─ Go-Live-Termin festlegen
│
└─ Dealstage: "Kaufvertrag geschlossen" oder ähnlich

---

### PHASE 10: GO-LIVE & KUNDENEINSTIEG (ONBOARDING)
├─ Testzugang deaktivieren
├─ Produktiven Zugang aktivieren
│
├─ Intensives Onboarding (erste 2-4 Wochen):
│  ├─ Täglich verfügbar sein
│  ├─ Schnelle Problemlösung
│  ├─ Zusätzliche Schulung bei Bedarf
│  ├─ Regelmäßige Überprüfungen
│  └─ Optimierungsvorschläge machen
│
├─ Follow-up-Gespräche:
│  ├─ Nach 1 Woche: Erste Eindrücke
│  ├─ Nach 2 Wochen: Größere Probleme klären
│  ├─ Nach 1 Monat: Ausführliches Zwischenfazit
│  └─ Nach 3 Monaten: Umfassendes Erfolgsgespräch
│
└─ Dealstage: "Kunde aktiv" oder "Go-Live erfolgreich"

---

### PHASE 11: LANGFRISTIGES KUNDENMANAGEMENT
├─ Regelmäßiger Support
│  ├─ Ticketsystem für Anfragen
│  ├─ Technische Probleme lösen
│  └─ Monatliche Wartungen
│
├─ Beziehungspflege:
│  ├─ Monatliche Statusberichte
│  ├─ Quartalsweise Überprüfungsgespräche
│  ├─ Neue Funktionen erklären
│  └─ Best-Practice Tipps teilen
│
├─ Upselling & Expansion:
│  ├─ Neue Funktionen anbieten
│  ├─ Zusätzliche Lizenzen empfehlen
│  └─ Laufzeitverlängerung einleiten
│
└─ Dealstage: "Kunde (aktiv)" → "Laufend erneuert"

## WICHTIGE DEALSTAGES IN DIESER PIPELINE

1. **"Testpaket angefragt"** 
   - Start: Deal wird erstellt
   - Aktion: Qualianruf vereinbaren

2. **"Testpaket erfassen"** (Tom's Stage)
   - Kunde wurde erreicht und qualifiziert
   - Aktion: Tom erfasst Testpaket in Shopware

3. **"Testpaket erfasst"**
   - Testpaket ist fertig und versandt
   - Aktion: Erstes Beratungsgespräch führen

4. **"Verloren"**
   - Kunde nicht erreichbar (nach 6 Versuchen)
   - ODER: Feedback-Gespräch → Kunde möchte nicht kaufen

5. **"Kaufvertrag geschlossen"** (oder ähnlich)
   - Kunde hat sich für Bezahlversion entschieden
   - Aktion: Lizenzvertrag und Zahlungsabwicklung

6. **"Kunde aktiv"** oder **"Go-Live erfolgreich"**
   - Kunde nutzt Produktivsystem
   - Aktion: Laufender Support und Beziehungspflege

## BESONDERE REGELN & HINWEISE

⚠️ **AHMET YITIK PROVISION:**
- Affiliate darf erst NACH Testpaket-Erfassung Ahmet zugeordnet werden
- Grund: Provisionsvereinbarung (kostenloses Testpaket darf nicht über Affiliate laufen)

⚠️ **KONTAKTVERSUCHE:**
- 3 Anrufe vor WhatsApp/E-Mail
- 6 Versuche insgesamt über alle Kanäle
- Danach: "Verloren" → Deal abschreiben

⚠️ **SHOPWARE-EINTRAG:**
- Tom legt den Kunden an (nicht vorher)
- Mit kostenlosen Testpaket-Details
- Affiliate-Zuordnung erst danach

⚠️ **TERMINE:**
- Erstes Beratungsgespräch: Zeitnah zum Testpaket-Versand
- Feedback-Gespräch: Im Erstgespräch vereinbaren
- Beides in HubSpot als Termin eintragen
