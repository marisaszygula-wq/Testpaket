## 3 Fälle:

### 1. Salon will Testpaket
```
Du → Marisa/Tom schreiben:
"Salon [Name] möchte Testpaket. Kontakt kommt von mir."

→ Sie machen das fertig
→ Nach Test, wenn Salon kauft: DU BEKOMMST 20%
```

### 2. Salon kauft direkt
```
Du → Marisa/Tom schreiben:
"Salon [Name] kauft direkt. Kontakt kommt von mir."

→ Sie ordnen dich zu
→ Salon kauft: DU BEKOMMST SOFORT 20%
```

### 3. Provisionen checken
```
→ Geh ins Shopware-Dashboard
→ Dort siehst du live:
   - Deine Kunden
   - Deren Bestellungen
   - Deine Provisionen
```
